# Aether Frontier — Act I Prototype

**The Last Frontier** is the first playable campaign vertical slice.

## Play

Open `index.html` in a modern desktop or mobile browser. No server or dependency is required.

### Controls

- **WASD / Arrow keys:** move commander
- **Mouse:** aim
- **Mouse button:** attack
- **R:** restart after defeat

## Gameplay loop

1. Defend the village against enemy waves.
2. Travel to and secure the Aether Mine.
3. Defeat the Iron Scout Commander and its escort.
4. Collect Aether loot and the Crown Fragment.
5. Complete Act I.

The prototype contains RTS-style movement/combat, mission progression, enemy waves, an elite boss, boss health, XP, gold, Aether resources, loot drops, and a campaign-completion state. It is intentionally dependency-free so it can be served directly from GitHub Pages.
