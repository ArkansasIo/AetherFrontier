Aether Frontier

A pixel-art RTS + RPG strategy game set in a medieval frontier transformed by advanced Aether technology. Build kingdoms, command armies, develop characters, research technology, and fight through a 46-act campaign.

Play Act I Prototype Source on GitHub

46-Act Campaign

Long-form story campaign with RTS battles, RPG progression, missions, exploration, bosses and strategic decisions.

RTS + RPG

Command armies while developing commanders through attributes, classes, skills, equipment, crafting and research.

Multiplayer

Designed for single-player, LAN, hosted multiplayer and dedicated-server modes using a shared authoritative game model.

Cross-Platform

Native desktop/mobile builds and a browser client share campaign data and gameplay protocols.
